Что такое парсинг? Зачем он нужен?

Давайте разберем что это такие и зачем нужен

## **Парсинг это не сложно**

**Парсинг** — это процесс автоматического сбора данных и их структурирования.

**Парсинг** обычно применяют, когда нужно быстро собрать большой объем данных.

Чтобы начать парсить вам нужно скачать некоторые библиотеки питона в которых нет в обычном питоне. Сперва вам нужно в поисковике написать cmd. Затем заходите туда и прописываете pip --version. Оно должно вывести версию вашего pip. Если у вас выходит ошибка, то вы должны установить pip. Но по умолчанию если вы пользуетесь Python 2.7.9 (и выше) или Python 3.4 (и выше), PIP устанавливается вместе с Python по умолчанию (Windows 10).

## **Что такое pip?**

pip — система управления пакетами, которая используется для установки и управления программными пакетами, написанными на Python.  Это означает, что это инструмент, который позволяет вам устанавливать и управлять дополнительными библиотеками и зависимостями, которые не распространяются как часть стандартной библиотеки. Давайте начнем парсить.

## **Скачиваем нужные библиотеки**

pip install lxml **lxm**l — это библиотека, которая позволяет легко обрабатывать XML и HTML файлы, а также может использоваться для парсинга веб-страниц.

pip install requests **Requests** \- это HTTP-библиотека для языка программирования Python. Цель проекта - сделать HTTP-запросы более простыми и удобными для человека.

pip install beautifulsoup4 **Beautiful Soup** \- это пакет Python для анализа документов HTML и XML. Он создает дерево синтаксического анализа для проанализированных страниц, которое можно использовать для извлечения данных из HTML, что полезно для парсинга веб-страниц.

## **Начинаем писать код**

После того как вы сделали все то начинаем писать код:

```python
import requests #Импортируем библиотеки питона
from bs4 import BeautifulSoup
url = 'https://akipress.org/'
response = requests.get(url)
soup = BeautifulSoup(response.text, 'lxml')
print(soup)
```

## **Что произошло?**

Переменной url сохраняется адрес страницы, с которой будет поступать информация. Эта переменная затем передается функции requests.get(). Результат присваивается переменной response. Дальше используем конструктор BeautifulSoup(), чтобы поместить текст ответа в переменную soup. В качестве формата выберем lxml. Наконец, введем переменную.

Вот что происходит: ПО заходит на сайт, считывает данные, получает исходный код — все по аналогии с ручным подходом.

## **Прохождение по структуре HTML**

HTML — это HyperText Markup Language («язык гипертекстовой разметки»), который работает за счет распространения элементов документа со специальными тегами. В HTML есть много разнообразных тегов, но стандартный шаблон включает три основных: html, head и body. Они организовывают весь документ.

## **Парсинг HTML-разметки**

В HTML-документе хранится много информации, но благодаря Beautiful Soup проще находить нужные данные. Порой для этого требуется всего одна строка кода. Пойдем дальше и попробуем найти все теги span с классом text. Это, в свою очередь, вернет все теги. Когда нужно найти несколько одинаковых тегов, стоит использовать функцию find\_all().

