Если у вас уже установлен один из дистрибутивов Linux, тогда устанавливать Python не надо.

Достаточно проверить версию, открыв терминал (**`CTRL+ALT+T`****)** и прописать:

```bash
tsoonami@tsoonami:~$ python3 --version
Python 3.8.2
```

у меня установлена версия `3.8.2` \- и это стабильная рабочая версия. Если у вас стоит `Ubuntu 20.04` или `Linux Mint 20` то у вас уже должна быть последняя версия Python. Если же версия отличается, то пройдите по [`ссылке`](https://devacademy.ru/recipe/kak-ustanovit-python-38-v-ubuntu-1804), чтобы установить именно  `3.8`

Краткое объяснение версий:

-   последнее число 2 означает незначительные изменения, которые не повлияют на ваш рабочий код. Тоесть это фиксы багов и мелких ошибок.
-   второе число 8 - младшая версия (minor), изменяется при значительных изменениях функциональности, может в некоторых случаях повлиять на ваш код
-   первое число - старшая версия (major), изменяется при кардинальных изменениях программы и полностью отразится на вашем рабочем коде
