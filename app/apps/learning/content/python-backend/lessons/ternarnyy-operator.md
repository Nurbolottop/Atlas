Тернарный оператор - это присвоение значения переменной с помощью условия

Вспомним, как мы бы присваивали переменным значения через какое-то условие.

```python
age = int(input("Enter your age: "))

message = ""

if age < 18:
        message = "Forbidden"
else:
        message = "Welcome"

print(message)
```

В зависимости от числа, мы перезаписываем пустую переменную на одну их 2 сообщений.

Это же можно сделать с помощью тернарного оператора в одну строчку

```python
age = int(input("Enter your age: "))
message = "Welcome" if age > 18 else "Forbidden"
print(message)
```

мы получим с вами такой же результат. Но код стал намного красивее и читабельнее.

Мы записываем в переменную  message то или другое сообщение в зависимости от возраста, который к нам прилетает через  input

Рассмотрим следующий пример:

```python
my_passwords = ["qwerty", "12345678"]

user_input = input("Введите пароль: ")

access = "разрешен" if user_input in my_passwords else "запрещен"

print("Вход " +  access)
```

Если введеный нами пароль будет равен одному из двух в списке паролей, то мы получим Вход разрешен, если же ничего не совпадет, то мы получим вход запрещен
