Циклы предназначены для повторения определенного кода и для перебора значений в итерируемых типах данных. Итерируемый тип данных пока можете понимать как те типы данных, которые можно индексировать

Например :

Чтобы напечатать  "Hello world"  5 раз, мы с вами сделали бы так:

```python
print('Hello world')
print('Hello world')
print('Hello world')
print('Hello world')
print('Hello world')
```

Это же, мы сможем сделать в 2 строчки кода с помощью цикла  `for`

```python
for i in range(5):
        print("Hello world")
```

 или используя  `while`

```python
i = 5
while i != 0:
        print("Hello world")
        i -= 1
```

 Конечно, вы скажете  "Так здесь 4 строчки кода, не легче просто прописать?".  Но представьте ситуацию, когда вам нужно повторить это 10 тысяч раз.  Удобно?)

И так, существуют два типа циклов это  `for`  и  `while`

Между собой они немного отличаются, давайте же рассмотрим каждый по отдельности
