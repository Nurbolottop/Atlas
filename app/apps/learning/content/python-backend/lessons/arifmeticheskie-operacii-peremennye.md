И так, мы с вами установили Python, теперь можем поиграться с ним.

Для того, чтобы запустить `интерпретатор` Python, достаточно открыть терминал и ввести:

```bash
tsoonami@tsoonami:~$ python3
Python 3.8.2 (default, Jul 16 2020, 14:00:26) 
[GCC 9.3.0] on linux
Type "help", "copyright", "credits" or "license" for more information.

```

Примечание: официально версия Python 2 уже не поддерживается, поэтому все команды связанные с языком, запускаем через `python3`.

Для того, чтобы запустить первую программу, запишем следующее:

```bash
>>>print("Hello world")
Hello world
```

Мы получили нашу первую рабочую программу, которая выдает нам сообщение  
`"Hello world"`

Встроенная функция `print()`, выводит в консоль то, что получает в виде аргумента, в данном случае, аргументом является `строка``"Hello world"`. О строках мы поговорим чуточку позже. Скажу пока то, что все `строки` начинаются через `одинарные` или `двойные` кавычки, особого значения это не имеет, можно использовать и то, и другое.

### Комментарии в коде

Комментарии это части кода, которые будут проигнорированы при исполнении.  
Существуют 2 вида комментариев в Python

-   многострочныe - пишутся через тройные кавычки

    ```python
    """
    Это многострочный комментарий
    Здесь можно продолжать писать
    Это будет проигнорировано при исполнении
    """
    ```

-   однострочные - пишутся через `#`

    ```python
    # это однострочный комментарий
    ```

**Арифметические операции**

| Символ | Операция |
| --- | --- |
| + | Сложение |
| - | Вычитание |
| \* | Умножение |
| / | Деление (классическое или истинное деление) |
| // | Деление с округлением вниз |
| % | Деление по модулю (вычисляет остаток от деления) |
| \*\* | Возведение в степень |

Попробуем каждую из них:  


```bash
>>>print(1 + 1)
2
```

кстати, именно в консоли можно выводить и без `print()`

```bash
>>>2 - 1
1
>>>2 * 2
4
>>>4 / 2
2
>>>7 // 2
3
>>>7 % 3
1
>>>2 ** 2
4
```

**Операции сравнения**

| Оператор | Описание | Пример |
| --- | --- | --- |
| == | Если значения двух сравниваемых операнд равны, то условие становится истиной. | (6 == 8) не истина False |
| != | Если значения двух сравниваемых операнд НЕ равны, то условие становится истиной. | (5 != 2) истина True |
| \> | Если значение левого операнда больше чем значение правого операнда, тогда условие становится истиной. | (2 > 4) не истина False |
| &lt; | Если значение левого операнда меньше чем значение правого операнда, тогда условие становится истиной. | (9 &lt; 4) истина False |
| \>= | Если значение левого операнда больше или равно значению правого операнда, тогда условие становится истиной. | (1 >= 3) не истина False |
| &lt;= | Если значение левого операнда меньше или равно значению правого операнда, тогда условие становится истиной. | (2 &lt;= 3) истина True |

Примеры:

```bash
>>>2 == 4
False
>>>2 == 2
True
>>>4 > 3
True
>>>8 < 7
False
>>>10 / 2 > 4   # можно совмещать разные операции
True
>>>2 > 5 * 2
False
>>>2 != 4  # не равно
True
```

## Переменные

Из школьного курса математики мы все знаем, что такое переменные. В программировании принципы довольно схожи. Переменная — это «ячейка» оперативной памяти компьютера, в которой может храниться какая-либо информация.

Если брать жизненный пример, то переменная это подписанная коробка, где можно хранить всё, что угодно.

Например:

```bash
>>>number = 5
>>>number
5
```

То есть, мы объявили переменную с помощью знака `присвоения``"="`, куда сохранили число `5`. Не путайте знак присвоения `=` со знаком сравнения `==`

Теперь можем использовать нашу переменную:

```bash
>>>number + 5
10
>>>number * 3
15
```

Также, мы можем перезаписать ее:

```bash
>>>number = 10
>>>number
10
>>>number * 2
20
```

```bash
>>>name = "John"
>>>name
"John"
>>>surname = "Doe"
>>>surname
"Doe"
>>>name + surname
"JohnDoe"
>>>name + " " + surname  # добавляем пустой пробел между словами
"John Doe"
>>>name = "Mark"
>>>surname = "Twain"
>>>name + " " + surname
"Mark Twain"
```

Запомните: Python интерпертируемый язык программирования, значит весь код читается построчно, не может быть такого, что он прочитает 10 строчку раньше, чем 9 строку.  
Поэтому, если мы объявим такое же имя переменной ниже и запишем туда другое значение, то наша переменная перезапишется.

### Правила объявления переменных

-   Нельзя начинать название переменной с цифры  
    `5number = 5`  \- неправильно

    `5 = 5` \- неправильно

    `number_5 = 5`  \- правильно

-   В названиях переменных разрешаются только буквы латинского алфавита, цифры и нижний пробел `_`

    `first_name = "Mark"` \- правильно

    [`first.name`](http://first.name)` = "Mark"` \- неправильно

    `_ = 5` \- переменная также может состоять из одного пробела

-   Названия переменных должны четко указывать, что в них хранится или же иметь смысловую связь.

    `n = "Mark"` \- непонятно, что хранится в переменной

    `name = "Mark"` \- правильноe название

    `n = 5` \- неправильно

    `num = 5` \- правильно

    `number = 5` \- правильно

-   Используем для отделения слов [snake case](https://ru.wikipedia.org/wiki/Snake_case)

В переменных можно хранить различные типы данных.

### Множественное присваивание

Можно также объединить присваивание нескольких переменных в одну строку  
Например:  


```python
>>>num1, num2, num3 = 1, 2, 3
>>>num1
1
>>>num2
2
>>>num3
3

>>>name, surname, age = "John", "Doe", 20
>>>name
"John"
>>>surname
"Doe"
>>>age
20
```

### Свайп переменных

Можно поменять значения двух переменных в одну строку  


```python
>>>num1 = 10
>>>num2 = 20
>>>num1
10
>>>num2
20
>>>num1, num2 = num2, num1  #  меняем значения
>>>num1
20
>>>num2
10
```
