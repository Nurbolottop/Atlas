`Строки` (strings, тип данных “`str`”) – фрагменты (кусочки) текста или последовательность символов

Строки в питоне могут быть созданы с помощью одинарных, двойных и тройных кавычек.  
Например:

```python
name = "John"   #  двойные кавычки
surname = 'Nash'  #  используем одинарные кавычки
bio = """
John Nash is a talented Python developer.
He works at Google.
"""

print(bio)

"""
Мы получим следующее:

John Nash is a talented Python developer.
He works at Google.

"""

# c помощью встроенной функции  type узнаем тип
print(type(name))
"""
Мы получим следующее:

<class 'str'>

Тоесть, значение в переменной относится к классу  str (string)
"""
```

 Тройные кавычки в переменной означают такие строки, которые сохраняют свой вид написания. Тоесть, как вы напишите внутри, так оно и будет выводиться. Не путайте с многострочными комментариями. Комментарии пишутся вне переменных.

Рассмотрим следующий пример:

```python
sentence = 'John is a software engineer. He's a python developer'
print(sentence)

File "<stdin>", line 1
    sentence = 'John is a software engineer. He's a python developer'
                                                ^
SyntaxError: invalid syntax
```

Программа вываливает нам синтаксическую ошибку `SyntaxError`. Дело в том, что после слова  `He` мы поставили такую же одинарную кавычку от сокращенного слова  `He is`.  Но интерпретатор думает, что в этом месте мы закончили строку и не понимает код дальше. Чтобы избежать таких случаев, обычно мы используем 2 способа:

```python
#  ставим \ перед символом
sentence = 'John is a software engineer. He\'s a python developer'

# или для создания строки используем двойные кавычки
# а для сокращения одинарные
sentence =  "John is a software engineer. He's a python developer"
```

### Форматирование строк

-   метод  `.format()`

    ```python
    name = 'John'
    surname = 'Nash'
    company = 'Google'
    bio = """
    {0} {1} is a talented Python developer.
    He works at {2}.
    """.format(name, surname, company)

    print(bio)
    """
    Мы получим следующее:

    John Nash is a talented Python developer.
    He works at Google.

    """
    ```

-   c помощью `f string` (Python 3.6+)

    ```python
    name = 'John'
    surname = 'Nash'
    company = 'Google'
    bio = f"{name} {surname} is a talented Python developer.\nHe works at {company}."

    print(bio)
    """
    Мы получим следующее:

    John Nash is a talented Python developer.
    He works at Google.

    """
    ```

    `\n` \-  означает перенос на новую строку

### Конкантенация

Конкантенация - это склеивание строк через оператор  `+`

```python
bio = "John" + " Nash" + " is a talented Python developer.\nHe works at " + "Google"
#  обратите внимание на пробелы. Пробел для питона считается отдельным символом

print(bio)
"""
Мы получим следующее:

John Nash is a talented Python developer.
He works at Google.

"""
```

### Метод  `str()`

 Для того, чтобы склеить разные типы данных,  используем специальные функции преобразования  
Пример:

```python
name = 'John'
surname = 'Nash'  
age = 25  # (int)

print(name + " " + surname + ". He is " + age + " years old")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: can only concatenate str (not "int") to str
```

 Мы получим ошибку, так как мы пытаемся склеить в строку числовой тип в переменной  `age`

Чтобы исправить это, преобразуем  `age`  в строку:

```python
name = 'John'
surname = 'Nash'  
age = 25  # (int)

print(name + " " + surname + ". He is " + str(age) + " years old")

Output:
John Nash. He is 25 years old
```

### Получение пользовательского ввода

  Функция  `input()`

Эта функция позволяет нам получить пользовательский ввод и сохранить его куда-нибудь в переменную и использовать в дальейшем:

### Индексы

Индексы это нумерация значений (символов) внутри `итерируемых` (где можно пробежаться по каждому символу или значению по отдельности) типов данных. Иными словами это порядок или очередь, только запомните, что в программировании всё начинается с нуля.  


```python
bio = 'John Nash'
       012345678 <- индексы каждого символа
```

Заметьте, что у пробела тоже есть индекс, так как он тоже является отдельным символом

| Символ: | d | t | a | b | h | i | r | y |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Индекс: | 5 | 3 | 6 | 0 | 4 | 1 | 2 | 7 |
| Обратный индекс | -3 | -5 | -2 | -8 | -4 | -7 | -6 | -1 |

### Срезы

Так как строковые значения -- это всего лишь последовательность символов, мы можем получить индивидуальные символы. Производится такая операция с помощью квадратных скобок:

```python
language = 'Python'
print(language[2])

Output:
t
```

Вы можете сказать, “ой, t ведь третяя буква!”. Да, только в мире программирования это не так :)

Мы также можем получить целый кусочек с помощью квадратных скобок:

```python
flavor = 'birthday cake'
print(flavor[:3])

Output:
bir
```

то есть, не указываем начальный индекс, достаточно лишь указать конечный. Тот же принцип применим в получении куска строки начиная от определенного индекса до конца:

```python
print(flavor[5:])

Output:
day cake
```

Получение кусков строки с ее конца:

```python
print(flavor[-1])

Output:
e


print(flavor[-2])

Output:
k
```

Получение кусков строки через каждые 2 символа:

```python
flavor = 'birthday cake'
print(flavor[::2])

Output:
brha ae


#… через каждые 3:
print(flavor[::3])

Output:
btace
```

```python
My name is      Vasya. That's my name.
```

То же самое, но выровненное по левому краю:

Python

```python
>>> print "My name is %-10s. That's my name." % (name)
My name is Vasya     . That's my name.
```

Когда это может быть полезно:

```python
>>> drinks = {'Long Island': 3, 'Bloody Mary': 2, 'Margarita':4}
>>> print "%-15s%-5s" % ("Name", "Qty")
Name           Qty
>>> for k,v in drinks.items():
...     print "%-15s%-3s" % (k, v)
...
Bloody Mary     2
Long Island     3
Margarita       4
```

Если понадобится вывести целую часть числа:

```python
>>> num = 12.34

```

```python
>>> age = 25
```

## **Встроенная функция format()**

Работает так:

Python

```text
str.format()
```

В строке "поля для замены" заключаются в фигурные скобки `{}`. Все, что не заключено в скобки, воспринимается как обычный текст, которые копируется в неизменном виде. Чтобы передать в тексте символы фигурных скобок, их дублируют: `{{` и `}}`.Поля для замены форматируются следующим образом:

```text
поле_для_замены    ::=  "{" [имя_поля] ["!" конверсия] [":" спецификация] "}"
имя_поля           ::=  имя_аргумента ("." имя_атрибута | "[" номер_элемента "]")*
имя_аргумента      ::=  [идентификатор | integer]
имя_атрибута       ::=  идентификатор
индекс_элемента    ::=  integer | строковый индекс
строковый_индекс   ::=  <любой символ кроме "]"> +
конверсия          ::=  "r" | "s" # str или repr
спецификация       ::=  <описано ниже>
```

где

```text
спецификация  ::= [[заглушка]выравнивание][знак][#][0][ширина][,][.точность][тип]
заглушка      ::= <любой символ>
выравнивание  ::= "<" | ">" | "=" | "^"
знак          ::=  "+" | "-" | " "
ширина        ::=  integer # ширина поля
точность      ::=  integer # знаки после десятичной запятой
тип           ::=  "b" | "c" | "d" | "e" | "E" | "f" | "F" | "g" | "G" | "n" | "o" | "s" | "x" | "X" | "%"
```

Записывается так:

Python

```python
>>> print """\n{0}
... Сидел на стене
... {0}
... Свалился во сне.""".format('Шалтай-Болтай')

Шалтай-Болтай
Сидел на стене
Шалтай-Болтай
Свалился во сне.
```

Как видите, этот способ гораздо гибче оператора '%', так как одни и те же значения мы можем использовать повторно и в любом порядке. Также можно передать именованные аргументы, и тогда обращаться к ним будем не по номерам, а по именам.

Еще пример форматирования:

Python

```python
>>> toc = (
... ('Первая глава', '3'),
... ('Вторая глава', '150')
... )
>>> for line in toc:
...   print('{:.<30}{}'.format(*line))
...
Первая глава.......3
Вторая глава.......150
```
